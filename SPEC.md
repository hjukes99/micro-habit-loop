# SPEC — Micro Habit Loop

## App
Micro Habit Loop helps solo builders lock in one tiny daily habit with a fast check-in and a visual streak.

## Target User
- Busy solo founders and creators
- People who want consistency without complex planning tools

## MVP Scope
1. Define one habit (name + optional target minutes).
2. Daily check-in endpoint/CLI flow to mark habit done.
3. Persist check-ins in local JSON storage.
4. Calculate and display current streak + longest streak.
5. Show last 14 days status in a compact text grid.
6. Include smoke tests for streak calculation and data write/read.

## Non-Goals (for this first pass)
- Auth
- Multi-user support
- Cloud sync
- Notifications
- Mobile app
